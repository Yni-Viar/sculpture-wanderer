# Sculpture Wanderer

Available on [GameJolt](https://gamejolt.com/games/wanderer/1099176), [itch.io](https://yniviar.itch.io/sculpture-wanderer)

## About project
Infinite forest game (or generator)

Walk in the forest and look at the sculptures, maybe you'll get something for you...

Press F1 to view controls

> Actually, I got inspired from Tale of Tales(tm) games
> I felt their thoughts, and decided to create an ART game.

## Requirements to play

- 🐧Linux distribution from 2024 and newer

   > x86-64 or arm64 binaries available

- 🪟Windows 10 (all updates (build 14393 and higher is recommended)) and 11 (all updates)
   > x86-64 or arm64 binaries available

   > You can still access Web version for Windows 7 - 8.1 by using Supermium.

- 🤖Android 7.0 and newer (mid-range device)

   > arm64 and armv7 binaries available

- 🌐Modern browser (Chromium-based, Firefox and Edge)

- 🖥️ Hardware requirements
   - OpenGL 3.3/ES 3.0 minimum, Vulkan support recommended
   - display resolution > 1280x720 (except Android) recommended
   - Mouse/touch or keyboard support.

## Building from source
### Requirements to build

The project uses Godot 4.7.x as a base.

### Building regular version

1. Project->Export
2. Choose your platform (e.g. Windows/Linux/Android)
